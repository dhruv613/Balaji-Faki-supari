# 08 — Screenshot Index

All images are PNG files in `screenshots/`. **desktop/** = 1440 × 900 viewport (full-page capture), **mobile/** = 390 × 844 at 2× pixel density (full-page capture), **interactions/** = drawers, dialogs, validation, success/error/loading states, mobile drawers. While a drawer, dialog or toast is open the capture is the **viewport only** (Playwright cannot stitch fixed layers into a full-page image); for tall drawers the viewport was lengthened first so the whole drawer is visible. Filenames ending `__mobile` / containing `mobile` are 390 px versions.

Data states: **empty-state** = freshly seeded catalogue + store settings with **no orders**; **populated** = 20 demo orders in every status, 8 demo customers, 3 reviews and 3 refunds created through the real API; **after-workflows** = after the UI-driven mutation tests. All people, phones, e-mails, payment images and QR images are fictitious demo data; no secret or token appears in any image (the password field is masked and the demo e-mail is a throw-away `@example.test` address).

**Total: 151 screenshots** — desktop 29, mobile 33, interactions 89.
